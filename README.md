# 全港中學一覽表（2025/26）

以表格列出全港 441 所中學的校名、區域、學校類別、主題及關注事項，可搜尋、篩選、排序。

主題為按 16 類（自主學習、價值觀、身心健康、全人發展、學與教、國民教育、AI/STEM、關愛校園、語文、學習多樣性、環保、閱讀、生涯規劃、教師專業、資優、家校合作）以關鍵詞多標籤自動歸類，屬整理結果，非官方分類；點表格內主題標籤可即時篩選。

## 檔案

| 檔案 | 說明 |
|---|---|

## 資料來源

- 校名、區域、學校類別、關注事項：家校會《中學概覽 2025/2026》（教育局／家庭與學校合作事宜委員會）
  每校資料頁：`https://www.chsc.hk/ssp2025/sch_detail.php?...`
- 關注事項摘自各校概覽 PDF「學校特色 → 學校關注事項」一欄，由學校自行提供及核實。


## 近三年學校報告摘要

- 由各校官網自動搜尋《學校周年報告》PDF（2022/23–2024/25），抽取「關注事項」標題及「成效／成就」段落。
- 覆蓋：124 / 441 校（265 個校年），其中 83 校有中文內容，其餘為英文報告（原文摘錄，標示「英文原文」）。
- 未收錄的學校：官網未公開可讀 PDF（Google Drive／需登入／JS 內嵌）或網站無法連線。
- 內容為**原文摘錄**，未經人工改寫；數字與結論以報告原文為準。

## 說明與限制

- 涵蓋《中學概覽》收錄的 441 所本地中學，不含國際學校及私立獨立學校。
- 最新官方概覽為 2025/26 學年版；2026/27 版本通常於每年 12 月出版。
- 22 所學校在概覽中未填報關注事項，表中標示「概覽未列明」。
- 本專案為資料整理，非官方出版物；如有差異，以學校及教育局公布為準。
